# Web Programming Using ASP.NET Core and MVC

A complete classroom-ready guide for learning **ASP.NET Core** and **MVC**, prepared according to the official Aptech curriculum.

This course takes students from the fundamentals of ASP.NET and ASP.NET Core to building modern, cross-platform web applications using the MVC pattern, Entity Framework Core, authentication, and real-world architecture practices.

---

## About This Course

- Built with **React** + **Docusaurus**
- Hosted on **GitHub Pages**
- Content is based on the official book
- Every session ends with:
  1. **Summary**
  2. **Test Your Knowledge**
  3. **Try It Yourself**

---

## Course Structure

The course currently contains **10 sessions** (based on the available official book material). Each session is designed for approximately **2 hours**.

| Session | Title |
|---------|-------|
| 01 | Introduction to ASP.NET and ASP.NET Core |
| 02 | Working with ASP.NET Web Forms, Controls, and Events |
| 03 | Working with ADO.NET and Entity Framework |
| 04 | Client-side Development Using ASP.NET Core MVC |
| 05 | More on ASP.NET MVC and Core MVC |
| 06 | Action Methods and Advanced Concepts in MVC |
| 07 | Enhancements in ASP.NET Core |
| 08 | .NET Core Architecture and Kestrel Web Server Implementation |
| 09 | Onion Architecture in ASP.NET Core – I |
| 10 | Onion Architecture in ASP.NET Core – II |

> **Note:** Sessions 11–15 and the full **eProject Guide** will be added once soon.

---

## Student Expectations

Students are expected to:

1. Read the lesson material carefully.
2. Type and execute the examples themselves.
3. Complete the **Try It Yourself** exercises.
4. Attempt the **Test Your Knowledge** questions.
5. Practice outside the classroom.
6. Build the final eProject.
